These are a few projects I had wanted to build for some time but hadn't been able to prioritize. With the help of agentic coding, I recently turned them into working tools. Below is a brief introduction to each, with links to explore the projects and their source code.

### Spin Texture Atlas

An interactive atlas of magnetic spin textures and their topological charge. It lets you explore spin structures such as skyrmions, merons, and vortices, change their parameters, and compare the spin field with its charge density and total winding.

The project pairs a React and Three.js visualization with an implementation of the texture generators and numerical topology calculations. It translates mathematical descriptions of spin textures into fields you can see and interact with.

[Explore the atlas](https://rnepal2.github.io/spin-textures/) / [GitHub repo](https://github.com/rnepal2/spin-textures)

### Myeloma Landscape

An integrated view of the multiple myeloma development landscape, bringing together public records on registered trials, therapies, sponsors, literature, funding, and regulatory actions.

The project draws data from public sources including ClinicalTrials.gov, PubMed, NIH RePORTER, FDA, DailyMed, and the European Medicines Agency. It organizes these records into a browsable reference with source links and documented retrieval and classification methods. It is an independent research and insights tool based on public data; its summaries describe the retrieved records rather than rank the clinical value of therapies.

[Explore the landscape](https://myeloma-landscape.pages.dev/) / [GitHub repo](https://github.com/rnepal2/myeloma-landscape)

### Metricairn

An open-source, self-hosted product analytics platform for tracking traffic, events, conversion funnels, and returning visitors.

Beyond the dashboard, Metricairn helps product owners investigate changes in activity using explicit query windows, collection-coverage checks, and saved evidence. Its Model Context Protocol (MCP) server lets an AI agent query the same analytics system.

[GitHub repo](https://github.com/rnepal2/metricairn) / [Use MCP](https://glama.ai/mcp/servers/rnepal2/metricairn)
